ビジネスコーチ プライバシーポリシー

最終更新日: 2025年2月22日

はじめに

ビジネスコーチ（以下「本アプリ」）は、ビジネスパーソンのキャリア成長を支援するコーチングアプリです。本プライバシーポリシーでは、本アプリがどのような情報を収集し、どのように使用するかを説明します。

ユーザーの同意について

本アプリは、初回起動時にOpenAI APIへのデータ送信について明示的な同意を求めます。同意いただけない場合、アプリのAIコーチング機能はご利用いただけません。

収集する情報

ユーザーが提供する情報

本アプリは、以下の情報をユーザーから収集します：

  • プロフィール情報: 名前、現在の役職、目標とする役職、会社名、業界
  • 会話内容: ユーザーとAIコーチとの対話内容
  • コーチングセッション: 課題設定、振り返り、アクションプランなどの記録

自動的に収集される情報

本アプリは以下の技術情報を自動的に収集します：

  • セッション回数
  • アプリの使用時間
  • デバイス情報（iOS バージョン、デバイスモデル）

情報の保存場所

ローカルストレージ

以下の情報はお使いのデバイス内にのみ保存され、外部サーバーには送信されません：

  • プロフィール情報
  • 会話履歴
  • セッション記録

これらのデータは、iOSの標準的なローカルストレージ（UserDefaults）に保存されます。

外部サービスへの送信

本アプリは、OpenAI API を使用してAIコーチング機能を提供しています。

送信されるデータ：

  • ユーザーのプロフィール情報（コーチングの文脈として）
  • 会話内容（直近10件まで）
  • 現在のメッセージ

送信先： OpenAI API (https://api.openai.com/)

OpenAIのプライバシーポリシー：
https://openai.com/policies/privacy-policy

情報の使用目的

収集した情報は以下の目的で使用されます：

  1. AIコーチング機能の提供: ユーザーの課題に対して適切なコーチングを行うため
  2. パーソナライズ: ユーザーの役職や業界に合わせたアドバイスを提供するため
  3. セッション管理: 会話の継続性を保つため
  4. アプリの改善: より良いコーチング体験を提供するため

情報の共有

本アプリは、以下の場合を除き、ユーザーの個人情報を第三者と共有することはありません：

  1. OpenAI API: AIコーチング機能の提供に必要な範囲で情報を送信
  2. 法的要請: 法律、規制、または法的手続きにより要求された場合

マーケティング目的での第三者への販売や提供は一切行いません。

データの保持期間

  • ローカルデータ: アプリを削除するまでデバイスに保存されます
  • OpenAIへの送信データ: OpenAIのデータ保持ポリシーに従います（詳細はOpenAIのプライバシーポリシーをご確認ください）

データの削除

ユーザーは以下の方法でデータを削除できます：

  1. 会話履歴の削除: アプリ内の「設定」→「会話履歴をクリア」
  2. プロフィールの削除: アプリ内の「設定」→「プロフィールをリセット」
  3. すべてのデータの削除: アプリをデバイスから削除

セキュリティ

本アプリは、ユーザーの情報を保護するために以下の対策を講じています：

  • ローカル暗号化: 重要なデータはiOSの標準暗号化機能により保護
  • HTTPS通信: OpenAI APIとの通信は暗号化された接続を使用
  • APIキーの保護: APIキーはアプリ内に安全に保存

ただし、インターネット経由の送信や電子的な保存方法は100%安全ではないことをご理解ください。

13歳未満の子供

本アプリは13歳未満の子供を対象としていません。13歳未満のお子様から個人情報を故意に収集することはありません。

プライバシーポリシーの変更

本プライバシーポリシーは随時更新される場合があります。変更がある場合は、このページに新しいプライバシーポリシーを掲載します。

重要な変更がある場合は、アプリ内で通知します。

OpenAI API使用に関する補足

本アプリは、OpenAI社が提供するGPT-3.5-turbo APIを使用しています。

OpenAIのデータ使用ポリシー:

  • API経由で送信されたデータは、モデルのトレーニングには使用されません
  • データは30日間保持され、その後削除されます（不正使用の監視目的）

詳細は OpenAI の API データ使用ポリシーをご確認ください：
https://openai.com/policies/api-data-usage-policies
